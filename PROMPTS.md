# AI prompts

## Tools used

- Copilot SDK in VS Code
- Repository shell, file inspection, patching, and test commands

## Prompts

The initial UI and calculator requests were supplied in the conversation that
created this repository. The latest correction request is preserved in the
session transcript and was used as the implementation specification.

## Manual review

The parser, typed errors, HTTP status mapping, reducer transitions, API
serialization, accessibility labels, responsive layout, Docker configuration,
and CI commands were reviewed manually. Backend tests, frontend tests, lint,
build, formatting, and `go vet` were run after the changes.
